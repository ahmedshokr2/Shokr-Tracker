# Shokr Tracker V2

واجهة عربية متوافقة مع الهاتف لتسجيل ومتابعة مواعيد الخصم والميني باك باستخدام Firebase Authentication وCloud Firestore.

## الملفات
- `index.html`: بنية الصفحة.
- `styles.css`: تصميم متجاوب.
- `app.js`: الدخول، إدارة السجلات، العد التنازلي، الاستيراد والتصدير.
- `firebase.js`: إعداد اتصال Firebase.
- `firestore.rules`: قواعد البيانات الخاصة بكل مستخدم.
- `README-AR.md`: التعليمات.

## نشر النسخة
1. احتفظ بنسخة احتياطية من المستودع والبيانات الحالية.
2. ارفع الملفات الستة إلى جذر المستودع نفسه، بجانب `index.html` الحالي.
3. تأكد أن إعداد GitHub Pages أو Vercel ينشر من جذر المشروع.
4. في Firebase Console > Authentication > Sign-in method فعّل Email/Password.
5. راجع قواعد Firestore قبل نشرها. القواعد الموجودة هنا تقصر الوصول على المسار `users/{uid}` لصاحب الحساب نفسه؛ لا تستخدم قواعد عامة.
6. افتح الموقع وسجّل الدخول، ثم استخدم زر استيراد الأرقام. الاستيراد يفحص زوج (رقم الهاتف + النظام) ويضيف السجلات الناقصة فقط.

## ملاحظات مهمة
- الاستيراد لا يحذف أي سجلات موجودة ولا يستبدلها.
- صدّر CSV كنسخة احتياطية قبل أي تغيير كبير.
- الخصم: الموعد القادم محسوب 34 يومًا من `cycleStart`. عدّاد العمليات في النسخة الحالية يبدأ من 0 ويُعاد ضبطه بعد إكمال 6 عمليات؛ راجع معنى بداية الدورة عند استخدام بيانات قديمة.
- الميني: الموعد الشهري يراعي قصر الشهور (مثل 31 يناير إلى آخر يوم في فبراير).
- لا تضع كلمات مرور أو أسرار حسابك داخل الملفات.
- إعداد Firebase Web config مُضمّن في `firebase.js`. هذا الإعداد ليس كلمة مرور، لكن يجب حماية قاعدة البيانات بالقواعد أعلاه.
