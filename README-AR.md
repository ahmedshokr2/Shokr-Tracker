# Shokr Tracker — إعادة بناء الواجهة

- يستخدم مشروع Firebase الحالي `shokr-tracker` ومسار البيانات الحالي `users/{uid}/numbers`.
- تسجيل الدخول عبر Firebase Authentication، دون نقل الحسابات إلى مشروع جديد.
- تصدير CSV احتياطي وفحص للتكرارات لا يحذف أو يدمج أي سجل.
- لا يوجد تنظيف تلقائي ولا استيراد بأرقام تخمينية؛ يلزم استعادة قائمة الأرقام الـ34 الأصلية قبل إعادة تفعيل الاستيراد.
- الخصم يُحسب بعد 34 يومًا، والميني في الشهر التقويمي التالي مع ضبط الشهور الأقصر.

## نشر آمن
1. نزّل نسخة CSV من الموقع الحالي قبل الاستبدال.
2. احتفظ بنسخة من ملفات المستودع القديم.
3. ارفع الملفات إلى فرع/مستودع تجريبي أولًا، ثم اختبر تسجيل الدخول وقراءة السجلات.
4. لا تستبدل قواعد Firestore الحالية إلا بعد مراجعتها؛ الملف `firestore.rules` مثال لقصر الوصول على بيانات كل مستخدم.
5. لا توجد عملية حذف جماعي في هذه النسخة. زر الحذف الفردي يطلب تأكيدًا.
